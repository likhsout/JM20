# Vercel Deploy — 1 Click
1. Go to vercel.com → New Project → Import Git Repository → likhsout/JM20 → Import
2. Framework: Next.js (auto)
3. Root Directory: jm2020-v2 (if you imported monorepo, set it; else keep root if you pushed only jm2020-v2)
4. Env Vars: NEXT_PUBLIC_SUPABASE_URL + NEXT_PUBLIC_SUPABASE_ANON_KEY
5. Deploy → you get https://jm20.vercel.app
6. Domains → Add jm2020science.com
